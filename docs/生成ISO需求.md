# 生成 ISO 需求

增加「生成 ISO」。对 Windows 10 与 Windows 11 安装镜像，按写入 U 盘的方式修改安装文件，另存为新的 ISO。原镜像保持不动。

修改的是 Windows 写死的硬件限制，包括 CPU、TPM 2.0，以及写入 U 盘时已经处理的同类检查。新 ISO 必须可以启动，供 Ventoy 启动安装。

## 标签页

两个标签页，内容不同，共用底部的进度条、状态栏与开始按钮。

- 两个标签页各自记住自己选中的镜像。切换时对调，生成 ISO 页选的镜像不会改掉写入 U 盘页的选择。
- 操作进行中不允许切换标签页。
- 写入 U 盘页里原本隐藏的高级选项，切回去时仍保持隐藏。

## 写入 U 盘

保持现有界面，包括设备选择、镜像选择和从网上拉取镜像。开始按钮的可用规则保持现状。

与生成 ISO 共用同一套进度与结果对话框：状态栏增加速度栏，结束后弹结果对话框。速度只取自真实字节数，格式化、百分比之类的加权进度不计入。

## 生成 ISO

新界面。不选择 U 盘，不格式化磁盘。镜像只从本机选择，不从网上拉取。

- 尚未选择镜像时，开始按钮为灰色。
- 已选镜像是 Windows 10 或 Windows 11 安装镜像时，开始按钮为亮色。
- 已选镜像不是上述安装镜像时，开始按钮为灰色，并显示红色文字，说明只接受 Windows 10 或 Windows 11 安装镜像。Windows 7、Windows 8、WinPE、Linux，以及只能整盘 DD 写入的镜像，都属于这种情况。
- 页面上提供三个按钮，点击后用默认浏览器打开对应地址：
  - Microsoft activation scripts 提供的 Windows 下载地址：https://massgrave.dev/genuine-installation-media
  - 微软官方 Windows 11 下载地址：https://www.microsoft.com/zh-cn/software-download/windows11
  - Microsoft activation scripts 开源仓库地址：https://github.com/massgravel/Microsoft-Activation-Scripts

点开始后依次选择新 ISO 的保存位置、确认要应用的 Windows 定制选项。两者任一取消都不算一次操作，不弹结果对话框。生成过程需要 `oscdimg.exe`：本机缺少时先询问，同意后从微软符号服务器下载并校验 SHA-256。

## 生成结果

新 ISO 与原 ISO 格式相同，保留原有文件系统和启动结构。只替换被修改的文件。

被替换的文件与同一套选项写入 U 盘后的安装文件一致。`install.wim` 保持完整，不按 FAT32 的 4 GB 限制拆分。分区、格式化，以及只为 U 盘准备的启动文件，不进入新 ISO。

实现上的取舍，供对照：

- 解包到临时目录，用 `oscdimg` 以 `-h -m -o -u1 -udfver102` 重建 ISO-9660 与 UDF 双文件系统。必须两者兼具：El Torito 启动镜像只能读 ISO-9660；而微软的 ISO-9660 实现不支持 multiextent，大于等于 4 GB 的文件会被静默截断，`install.wim` 会坏掉，所以文件数据要从 UDF 树读。
- 不使用 Joliet。`oscdimg` 会拒绝卷标长度超过 16 字符的 Joliet 卷，而 Windows 安装镜像的卷标通常更长且被启动程序引用。
- 卷标沿用原镜像。启动程序按卷标找盘，改名可能导致无法启动。
- 启动参数从原镜像读取后以 `-bootdata` 传入，重建完成后再自行修补 El Torito 引导信息表（syslinux/isolinux 需要）。
- `oscdimg` 无法生成 Rock Ridge 扩展，原镜像的符号链接会在新 ISO 中丢失。

## 进度显示

写入 U 盘和生成 ISO 时，都要显示当前正在写入的文件，以及当前写入速度。

- 当前文件显示在状态栏左侧，只显示文件名和大小，例如 `install.wim (4.7 GB)`。不显示目录，因为状态栏宽度有限，长路径会被 `DT_PATH_ELLIPSIS` 压缩，反而把文件名和大小挤掉。
- 速度显示在状态栏右侧、计时器左边，按大小自动换算成易读单位，例如 `B/s`、`KB/s`、`MB/s`、`GB/s`，不直接显示原始字节数。每 500 毫秒采样一次，并用指数平滑（新值占 1/4）压制抖动；字节数回退时直接重设基准，避免负增量算出虚高速度。
- 百分比形式的进度（如 `oscdimg`、`dism` 输出的百分比）没有字节计数含义，不显示速度。

各阶段实际能显示的粒度：

| 阶段 | 左侧显示 | 速度 |
| --- | --- | --- |
| ISO 解包（UDF / ISO9660） | 文件名与大小 | 有 |
| 写入 U 盘 | 取决于数据来源，见下 | 有 |
| 应用 Windows 镜像（wimlib） | 只能显示阶段说明 | 有 |
| `oscdimg` 打包 | 目标 ISO 的文件名 | 无 |

写入 U 盘分两种数据来源：整盘镜像直接按字节写入时只有字节计数，没有文件名可显示；`install.wim` 解包时 wimlib 只提供已处理字节数和文件计数，不提供当前文件名，因此只能显示阶段说明。

`oscdimg` 的输出只有百分比，没有字节计数，所以打包阶段不显示速度。

## 完成提示

生成 ISO 结束后弹出对话框，说明是否成功，以及新 ISO 的保存位置和其他结果信息。

写入 U 盘结束后同样弹出对话框，说明是否成功，以及写入的设备和结果信息。

两种情况都覆盖取消与失败：取消时说明「未生成 ISO」或「未写入介质」，失败时说明失败原因。

对话框要点：

- 只有点开始按钮触发的操作才弹。计算哈希、保存镜像不弹。
- 在保存位置或定制选项对话框里取消，以及写入开始前的确认提示里取消，都不算一次完成的写入，不弹结果对话框。
- 成功时显示新 ISO 的完整路径（不是文件名），写入 U 盘时显示所选的设备名。
- 失败时显示标题与系统错误原因。
- 生成 ISO 失败时不保留 `created_iso_path`，对话框里不会出现上一次的路径。
